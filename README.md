## 📖 Descripción del Proyecto

**E-Commerce Backend API** es una solución backend completa diseñada para gestionar las operaciones fundamentales de una tienda en línea moderna. Construida desde cero sobre **Laravel 13**, esta API implementa las mejores prácticas de arquitectura de software, patrones de diseño y capacidades avanzadas asistidas por Inteligencia Artificial (**ChatGPT** y **Gemini**).

---

## 🚀 Funcionalidades Clave

- 🔐 **Autenticación y Autorización:** Gestión de usuarios, roles y permisos con JWT / Sanctum.
- 📦 **Gestión de Catálogo:** Productos, categorías, marcas, atributos y variaciones de inventario.
- 🛒 **Carrito y Órdenes:** Procesamiento de pedidos, estados de compra y pasarelas de pago.
- 🤖 **Integración con IA (ChatGPT & Gemini):** Generación automática de descripciones de productos, atención al cliente inteligente y recomendaciones avanzadas.
- ⚡ **Optimización y Caching:** Consultas eficientes, eager loading y caché de alta velocidad.
- 🧪 **Pruebas Automatizadas:** Cobertura de tests de integración y endpoints API.
